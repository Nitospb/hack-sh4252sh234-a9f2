# Модели и возможность локального обучения

Проверено 25 октября 2026 на Apple M4, 16 GiB общей памяти, PyTorch 2.10.0,
Python 3.12, MPS. Машинный отчёт: `../pipeline/output/local-benchmark.json`
после публикации обновлённого каталога.

## Что уже готово

В проекте есть предобученная `intfloat/multilingual-e5-small`: 117 653 760
параметров, эмбеддинги размерности 384, оригинальный Torch checkpoint и
квантованная ONNX-копия. Отдельный готовый cross-encoder reranker используется
для оценки пары объект/фрагмент. Веса обеих моделей получены ранее; команда
применяла их к нашему корпусу, но не обучала на нём заново. Эмбеддинги,
каталог, пороги, MMR и пользовательские реакции не являются дообучением весов.

Подтверждений собственного обученного checkpoint, журнала эпох или оценки
дообученной модели в текущем репозитории/полном релизе нет. Генеративная LLM
вызывается отдельным внешним API; она также не обучена нами на этих новостях.

## Реальная проба на этом компьютере

`benchmark_local.py` загрузил локальные веса и проверил:

- Инференс: 192 фрагмента, batch=8, максимум 384 токена, 2,353 секунды
  после прогрева, 81,599 фрагмента/с. Векторы конечны и нормализованы.
- Полный обратный проход по E5 и AdamW в float32, batch=2, 20 шагов:
  первый 1,161 секунды, последующие примерно 0,38–0,40 секунды.
  Loss и градиенты конечны; рабочие веса не сохранялись и не менялись.
- После последнего шага: выделенная MPS память 1,758 GiB, память драйвера
  4,675 GiB; пиковый RSS процесса 1,456 GiB. Эти счётчики общей памяти
  пересекаются, складывать их как независимую RAM нельзя. Это не измерение
  пика всей системы.

**Дообучение этой E5 локально возможно** с небольшим batch. Проба короткая:
она не измеряет длительное снижение частоты, время полного прохода или качество
обученной модели. Полный запуск может занимать от десятков минут до часов; сначала нужен более
долгий замер на выбранной длине/схеме обучения. Простая экстраполяция измеренных
шагов на 7 733 пары и batch=2 даёт около 25 минут чистых шагов на эпоху,
без токенизации, валидации, сохранений и длительного нагрева. Это нижний
ориентир, а не обещанное время обучения. Для экономии памяти можно заморозить
энкодер и обучать отдельную небольшую модель на готовых векторах. Доступность
MPS не гарантирует поддержку любой другой архитектуры или операции.

Также полностью пересчитан каталог: 21 419 новых/изменённых фрагментов,
28 496 переиспользованных; основная сборка завершилась за 368,4 секунды.
Исходная длинная сборка с batch=24 переполнила память MPS; в рабочем
инференсе теперь batch≤8, фиксированный padding, освобождение временных
тензоров/кэша и включённый ограничитель памяти. Повторный полный прогон прошёл.

Пробные веса удалены вместе с процессом; рабочие веса не изменены, обученная
модель после теста не появилась. Пары заголовок/текст использованы исключительно
для проверки ресурсов, не в качестве эталонной разметки релевантности.

## Какие данные использовать

Финальный `imports/alfa-final-dataset-2026-10-25-0900/data/training-news.jsonl`
содержит 7 733 новости за зафиксированный месяц с известными датами, без
`accessible_excerpt` и точных дубликатов text_hash. Полный объединённый каталог
содержит больше записей, включая неизвестные даты и материалы для проверки;
его нельзя целиком объявлять обучающим набором. Telegram исключён из ML.

Словарь из 10 000 тем, 1 000 объектных групп, отраслевые совпадения и подборки
`needs_review` не равны ручным положительным/отрицательным примерам. Строгие
автоматические назначения тоже не являются независимым эталоном.

Для дообучения релевантности сначала нужны пары «объект/интерес → новость» с
проверенными положительными и сложными отрицательными примерами. Отраслевой
контекст следует отличать от упоминания конкретного объекта. Отдельный
контрольный набор должен оставаться вне обучения и подбора порогов. Делить
нужно по времени и группам дубликатов/перепечаток, а не случайным чанкам.
Метрики: Recall@k/MRR/nDCG для поиска, precision/recall назначения объекта,
сравнение с неизменённой E5. Сейчас измеренных значений на ручном эталоне нет.

Адаптация на парах заголовок/текст возможна как отдельный эксперимент со слабым
сигналом, но улучшение рекомендаций из неё не следует автоматически. Она не
заменяет проверку релевантности и не обучает событийные утверждения bt_.

## Повторить проверку

В окружении Python 3.12 установите `requirements-gpu.lock`, затем из каталога
приложения `Alfa-Hackaton`:

```bash
python news_matching/benchmark_local.py \
  --input ../imports/alfa-final-dataset-2026-10-25-0900/data/training-news.jsonl \
  --device auto --batch-size 8 --training-batch-size 2 --training-steps 20 \
  --output pipeline/output/local-benchmark.json
```

Проверка не обращается к LLM API и не скачивает модели. MPS, CUDA и CPU
поддерживаются для пробного обратного прохода; инференс на MPS использует
Torch, на остальных устройствах — CPU ONNX. Для чистого измерения не запускайте
одновременно пересчёт каталога и пробу обучения.

Первичные документы: [карточка E5](https://huggingface.co/intfloat/multilingual-e5-small),
[PyTorch MPS](https://docs.pytorch.org/docs/stable/notes/mps.html),
[Apple Metal/PyTorch](https://developer.apple.com/metal/pytorch/).
