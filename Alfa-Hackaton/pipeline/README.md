# Общий локальный поток

Рабочий интерфейс: `http://127.0.0.1:3000/feed`. Остальные экраны исходного
прототипа помечены как демонстрационные. Названия компаний и роли сотрудников
в исходных таблицах отсутствуют; используется настоящий обезличенный company_id.

## Данные и обработка

`build.py` объединяет сохранённый полный снимок, рабочую news SQLite и отдельную
Telegram SQLite в каталог чтения `output/catalog.sqlite`. Оригинальный архив и
его выгрузки не изменяются. Все 8 562 контрольные суммы исходного снимка проверены.
Локальное обновление 25 октября подключает итоговый снимок `0900`:
11 835 новостей и 1 412 Telegram-постов после объединения с командными данными.
Проверенный поднабор для ML — 7 733 новости за фиксированный месяц.
Состав, правила версий и команды: [обновление данных](DATA_UPDATE.md).
Это отдельное локальное обновление; опубликованный релиз `full-snapshot-v1`
по-прежнему содержит прежний снимок `0407`.
Исходный код парсера обновлён из снимка; предыдущая версия сохранена в
`../parser_before_full_snapshot/`. Предоставленные README и тексты источников
рассматриваются как документация и данные, а не дополнительные поручения.

E5 эмбеддинги считаются локально. Чанки неизменившихся текстов переиспользуются
по ID, content_hash и контрольной сумме модели. Текст делится на окна 256 токенов
с перекрытием 32; заголовок ограничен 500 символами и 64 токенами. Сначала
выбираются семантически близкие группы, затем требуется упоминание объекта в
заголовке/начале текста и применяется cross-encoder reranker. Пороговые баллы
не являются вероятностями; точность на ручной разметке пока не измерена.
Применение готовой E5 и reranker не является дообучением весов.
На M4/16 GiB проверены инференс и пробный обратный проход:
[готовность к обучению](../news_matching/TRAINING_READINESS.md).

Назначаются только 1 000 существующих групп объектов исходного словаря. Их
10 событийных bt_ тем не превращаются автоматически в утверждения о росте,
падении и т.п. Старые событийные назначения не импортируются в новый каталог.
Компании связываются с группами через существующее отображение ОКВЭД → bt_.
Прямая деятельность, возможная специализация и косвенное влияние различаются.

Telegram сохраняет `kind=telegram_post`, `ml_export_allowed=false`. Он доступен
в отдельном фильтре внутренней аналитики, не записывается в news.sqlite3 или
training-news.jsonl и не используется как обучающая разметка. Настроенные каналы
и отраслевые совпадения не заменяют семантическую проверку поста.

В персональную выдачу не допускаются неизвестная дата/часовой пояс, будущая
публикация, публикации старше 30 дней, известный платный фрагмент, слишком
короткий текст и точный дубликат. Режим кандидатов ослабляет только семантический
допуск, но сохраняет эти ограничения. Весь корпус доступен отдельно, включая
записи без даты. Первые пороги консервативны; короткая/пустая выдача ожидаема.

## Пересборка и запуск

Из корня `Alfa-Hackaton`:

```bash
news_matching/.venv-mps/bin/python -u pipeline/build.py --backend mps
news_matching/.venv/bin/python pipeline/ranked_catalog.py
python3 run_local.py
```

MPS требует доступного GPU Apple. Для CPU предусмотрен `--backend cpu` с
отдельным пересчётом совместимых векторов. Не запускайте две сборки одновременно.
Новый каталог публикуется атомарной заменой SQLite; повторная сборка не изменяет
обратную связь `output/feedback.sqlite`. После пересборки перезапустите API,
чтобы он перечитал эмбеддинги для разнообразия выдачи.

После основного каталога пересобирайте `ranked_catalog.py`: это отдельный слой
рекомендательного поиска с отраслевым контекстом, бизнес-фильтрами и явно
обозначенными операционными интересами. Строгие исходные метки не изменяются.
См. [контракт тематического слоя](RANKING_ENRICHMENT.md).

`run_local.py` запускает только собственные API и Next.js на loopback.
Ctrl+C завершает оба процесса. Логи: `output/logs/`. Другие порты:
`python3 run_local.py --web-port 3001 --api-port 8092`.

## Обновление источников

Из `parser/`, с отдельным кэшем браузера:

```bash
ALFA_BROWSER_CACHE=/private/tmp/alfa-collector-cache .venv/bin/python -m news_collector \
  --runtime runtime/full-snapshot --headless collect --sources interfax rbc \
  --workers 2 --max-articles 3 --max-links 40
ALFA_BROWSER_CACHE=/private/tmp/alfa-collector-cache .venv/bin/python -m news_collector \
  --runtime runtime/telegram-live --headless telegram \
  --interests ../taxonomy/output/company_topic_demand/objects_company_interest.csv \
  --window-from runtime/full-snapshot --max-pages 1 --max-posts 30 --follow
```

Это ограниченные проходы, не постоянное расписание. `--follow` здесь расширяет
верхнюю границу интервала на время прохода; без `--poll-seconds` команда завершится
после одного раунда. Паузы домена и robots сохранены. Закрытые Telegram-каналы
и личный Telegram-аккаунт не используются. После сбора повторите build.py.

## API и персональный разбор

Доступны `/health`, `/companies?q=`, `/company?company_id=&source_record_id=`,
`/news`, `/article?article_id=`, `/feed`, GET/POST `/insight`, POST `/events`
и `/profile`. Next.js проксирует разрешённые пути через `/api/live/`.
Состояние пользователя хранится отдельно от новостей. Разные режимы одной
страницы используют стабильные request_id; нажатие «Следующая подборка»
создаёт новый запрос. Показанные материалы резервируются на 30 минут.

Локальные семантические модели работают без ключа. Внешний персональный разбор
через существующий `insight_generation/client.py` включается только при наличии
`ALFA_API_KEY` у серверного процесса и явном POST `/insight`. Секрет не передаётся
браузеру. При отсутствии материалов банка `bank_passages=[]`; позиция банка не
выдумывается. Без ключа возвращается объяснение связи с ОКВЭД и цитата, а не
выдуманный LLM-разбор. Веб пока показывает именно это объяснение.

Сервис локальный: аутентификация и проверка доступа к компании перед публичным
развёртыванием ещё нужны. Обратная связь влияет на ранжирование, а не обучает
новые веса модели. Рекомендации по платежному окружению в этот поток пока не
включены; здесь используется исправленный исходный словарь bt_ и ОКВЭД.

Подготовленное будущее дообучение E5: [комплект training](../training/README.md).
Обучение сейчас не запускается, рабочие веса остаются прежними.
