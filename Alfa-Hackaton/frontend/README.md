# Альфа-Бизнес

## Запуск

```bash
npm run dev
```

Общий запуск вместе с API из корня проекта: `python3 run_local.py`.
Рабочая лента: `/feed`. Сначала нужны `pipeline/output/catalog.sqlite` и
`pipeline/output/ranking.sqlite`; см. [общий поток](../pipeline/README.md).

## Рабочая рекомендательная лента

`src/screens/Feed/RecommendationFeed.tsx` подключена к реальному API.
Есть переключатель компании, пять быстрых отраслевых профилей, страницы по
24 новости, сохранённое, личные роли/темы, фильтры источников и просмотр текста.
Просмотр записывается при видимости не менее половины карточки в течение секунды
в активной вкладке. Загрузка карточки сама по себе не считается просмотром.
Лайки, сохранения и скрытие имеют отмену и хранятся в отдельной серверной SQLite.
Роль выбирается явно. Запросы страниц идемпотентны и сохраняются в sessionStorage;
версия тематического слоя входит в ключ. Новая страница исключает просмотренное
и уже отобранные материалы. Краткий разбор — экстракт источника и объяснение
тематической связи, не выдуманная позиция банка и не LLM-генерация.

## Структура

- `app` - маршруты и метаданные страниц.
- `src/screens` - сборка 11 экранов из компонентов.
- `src/components/UI` - настраиваемые каркасы карточек, кнопок, меток, таблиц и других элементов.
- `src/components` - компоненты оболочки, компании, инсайтов, аналитика и внутренних экранов.
- `src/providers` - выбранная компания и настройки ленты.
- `src/hooks` - сохранение состояния в браузере.
- `src/data` - типизированные демо-данные из макетов.
- `src/types`, `src/utils` - типы и функции отбора событий.
- `src/styles` - общие стили макетов и адаптивная раскладка.

## Экраны

`/`, `/feed`, `/event?id=e1`, `/chat`, `/profile`, `/sources`, `/trace`, `/settings`, `/clients`, `/quality`, `/architecture`.

## Демо-режим

Остальные экраны содержат демонстрационные данные и явно помечены. Реальная LLM
пока требует серверного ALFA_API_KEY; локальный поиск тем и MMR уже работают.

Выбор компании, настройки, интересы, уточнения контекста и оценки разборов сохраняются в `localStorage`. Порог значимости, показ возможностей и рекламных предложений применяются к интерфейсу. Настройки уведомлений и группы компаний сохраняются как демо-предпочтения; рассылки и пересчёт моделей не выполняются.
