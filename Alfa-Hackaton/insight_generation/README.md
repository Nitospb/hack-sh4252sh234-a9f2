# Персональная интерпретация новости

`explanation.py` предоставляет чистую функцию
`build_explanation(company, article, viewer_role='general', matches=None, industries=None)`
для локального интерфейса без модели. Возвращает короткое извлечение первых двух
предложений, реальные причины тематического отбора с пометкой предположения,
вопросы для выбранной роли, исходную ссылку и ограничения. Поля
`ai_generated=false` и `bank_view=null` отличают этот режим от модельного анализа.
Аргумент `matches=[]` явно отключает автоматическое сопоставление интересов.

`prompt.py` содержит системный промпт, JSON Schema ответа и сборку запроса.
`client.py` вызывает разрешённую LLM через шлюз организаторов. По умолчанию:
`z-ai/glm-5.3-flash`. Поиск по отчётам, OCR и интеграция с интерфейсом пока
не реализованы в этом модуле.

Установите зависимости из `insight_generation/requirements.txt`.
Задайте `ALFA_API_KEY` в окружении серверного процесса, затем запустите:

```bash
python3 insight_generation/client.py /absolute/path/input.json
```

`.env.example` перечисляет настройки, но `.env` автоматически не загружается.
Запасной адрес выбирается явно через `ALFA_BASE_URL`; автоматических повторов
и переключений нет. Максимум ответа — 4096 токенов. Возвращаются инсайт,
модель и usage шлюза. Тарифы неизвестны; usage не является стоимостью в рублях.
При исчерпании бюджета запросы прекращаются до сброса в 03:00 МСК.
Ключ не помещать в исходники или браузерный код.

Локальные проверки без сети и расходов:

```bash
python3 -m unittest discover -s insight_generation -p 'test_*.py'
```

Схема передаётся в системном промпте без предположений о поддержке шлюзом
структурированного вывода. Клиент проверяет JSON Schema, ID источников и
основные ограничения перед возвратом ответа. Фактическую обоснованность
рассуждений эта проверка сама по себе не гарантирует.

Входные поля описаны в SYSTEM_PROMPT. Передавайте отобранную новость,
подтверждённые признаки компании и найденные фрагменты отчётов с датами,
номерами страниц и ссылками. Все ID должны быть уникальны в запросе.
Если фрагментов банка нет, передавайте пустой `bank_passages`.
Необязательный `viewer_role` — явно выбранная роль для адаптации вопросов и
приоритетов, а не установленная по данным должность пользователя.

```bash
python3 insight_generation/prompt.py /absolute/path/input.json
```

Интерфейс выводит: событие → почему важно компании → позиция банка →
применение AI → риски/возможности → что проверить. Источники раскрываются
по ID из исходного запроса. Для `bank_view=null` блок мнения банка скрывается
или показывается сообщение об отсутствии подходящего материала.
`needs_context` требует показать недостающие сведения; `not_relevant`
не следует включать в персональную ленту.

Перед показом ответа необходимо проверить JSON Schema, существование всех
ссылочных ID и соответствие утверждений процитированным данным. Одного
промпта для гарантии качества недостаточно. Агентный цикл должен при нехватке
данных повторить поиск или запросить контекст, затем проверить результат.

Клиент отклоняет будущие новости и использованные материалы банка относительно
`as_of`, недатированные банковские источники, аналогии без ограничений переноса,
готовые персональные выводы без подтверждённого признака компании и безусловные
выводы по гипотезам. Для `needs_context` требуется список недостающих данных.
Это проверки контракта; они не заменяют проверку смысла и цитат.

Для интерфейса достаточно последовательности «Что произошло → Почему вам
показано → Возможное влияние → Что проверить», с отдельным раскрываемым блоком
банка и источниками. Локальное совпадение темы объясняет отбор, но не доказывает
последствия для бизнеса. Если LLM отключена, показывайте новость, темы и причину
совпадения; не называйте их полноценным аналитическим инсайтом и не добавляйте
шаблонную позицию банка. В истории фиксируйте режим подготовки результата.

Ключевые проверки качества при подключении модели:
- одна новость и две компании с разными признаками дают разные объяснения;
- отсутствие аналитики банка даёт `bank_view=null`;
- наличие кредита не превращается в утверждение о плавающей ставке;
- аналогичная ситуация помечена `analogous` с ограничениями;
- будущий относительно `as_of` отчёт не используется;
- нерелевантная новость не получает искусственного бизнес-обоснования.
