# Alfa-Hackaton

Персонализированная новостная аналитика для бизнеса.

Рабочая интеграция: [общий поток и запуск](pipeline/README.md).
После сборки каталога `python3 run_local.py` открывает API и веб-ленту
на `http://127.0.0.1:3000/feed` с реальными обезличенными компаниями,
новостями и отдельным Telegram-потоком аналитики.

- [Frontend](frontend/README.md): интерфейс прототипа.
- [Парсер](parser/README.md): сбор и хранение новостей.
- [Бизнес-таксономия](taxonomy/README.md): 10 000 тем, правила кандидатной привязки компаний и новостей, воспроизводимая сборка и отчёты покрытия.
