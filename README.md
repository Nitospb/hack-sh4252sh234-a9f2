# Alfa: новости и рекомендации для бизнеса

Весь рабочий проект: парсеры сайтов и публичного Telegram, исходные данные
компаний, словарь 10 000 бизнес-тем, локальные эмбеддинги, ранжирование MMR,
веб-лента, просмотры и реакции, модуль персональных ИИ-разборов.

Репозиторий публичный. Код хранится в Git. **Полные данные и веса моделей
приложены к релизу `full-snapshot-v1`** несколькими частями; состав и контрольные
суммы находятся в `release-manifest.json` этого релиза. Это не сокращённая
демо-выгрузка. Установленные зависимости, виртуальные окружения, ключи,
браузерные профили и кеши не поставляются.

## Восстановить весь комплект

Нужны GitHub CLI (`gh`) с доступом к этому репозиторию и Python 3.11/3.12:

```bash
gh auth login
python3 tools/restore_release.py
python3 tools/bootstrap.py
cd Alfa-Hackaton
python3 run_local.py
```

Открыть **http://127.0.0.1:3000/feed**. Данные скачиваются один раз. Проверяются
SHA-256 частей архива и каждого восстановленного файла. Без скачивания можно
изучать весь исходный код, конфигурации и тесты.

`bootstrap.py` устанавливает зависимости API/ML, парсера и веба из lockfiles.
Нужны Node.js 20.9+ и npm; для реального сбора сайтов — Chrome/Chromium.
Готовые эмбеддинги и каталог входят в релиз, GPU для просмотра ленты не нужен.
Для нового расчёта эмбеддингов на Apple MPS установите дополнительные зависимости
из `Alfa-Hackaton/news_matching/requirements-gpu.lock` в отдельное окружение.

## Что работает

- 6 095 новостей с сайтов и 1 404 Telegram-поста в общей базе; Telegram остаётся
  отдельным потоком аналитики и не превращается в обучающую разметку.
- 85 514 уникальных компаний, реальные ОКВЭД, исходные платежные/прочие таблицы.
- Исходный словарь 10 000 тем и исправленное отображение ОКВЭД → темы.
- Отдельные уровни объектной, отраслевой и событийной связи; операционные
  интересы явно обозначены предположениями.
- Пять быстрых профилей разных отраслей; на реальных векторах проверены
  страницы по 24 + 24 новости без повторов.
- MMR, разнообразие источников, история выдачи, просмотр при видимости ≥50%
  в течение секунды в активной вкладке, реакции и их отмена, сохранённое.
- Веса ранжирования: 60% компания/отрасль, 10% общее для бизнеса,
  10% популярность, 20% личные интересы. Это веса, а не жёсткие квоты карточек.
- Роль задаётся пользователем; просмотры и реакции меняют следующие подборки.
- Рабочая веб-лента `/feed`; остальные экраны прототипа помечены как демо.

## ИИ и стиль аналитики

Эмбеддинги E5 и reranker работают локально. Включены модели, токенизаторы,
готовые векторы, исходные тексты и воспроизводимые программы обработки.

`Alfa-Hackaton/insight_generation/` содержит промпт, JSON Schema, клиент шлюза
и проверку персонального разбора. Структура: что произошло → почему важно →
возможные последствия → что проверить → источники. Изученный PDF банка
используется как образец композиции, не как источник выдуманной текущей позиции.

Для **генеративного** анализа задайте `ALFA_API_KEY` в окружении серверного
процесса; параметры описаны в `.env.example` модуля. Ключ не входит в поставку.
Без ключа интерфейс показывает экстракт первоисточника и объяснение подбора,
не выдавая их за LLM-генерацию. Полноценный RAG по всем банковским PDF пока
не реализован. Нет заявления об измеренной точности рекомендаций.

## Структура

| Каталог | Содержание |
|---|---|
| `Alfa-Hackaton/frontend` | Next.js, карточки, выбор компании/роли, реакции |
| `Alfa-Hackaton/recommendations` | API, MMR, история, персонализация, тесты |
| `Alfa-Hackaton/parser` | Selenium, сайты, Telegram, конфигурации, тесты |
| `Alfa-Hackaton/taxonomy` | Темы, ОКВЭД, интересы и графовые исследования |
| `Alfa-Hackaton/news_matching` | E5, reranker, разметка и векторы |
| `Alfa-Hackaton/pipeline` | Объединение данных, отраслевой поиск, проверки |
| `Alfa-Hackaton/insight_generation` | Генеративный и локальный разборы |
| `data` *(релиз)* | Исходные таблицы, задание и банковские PDF |
| `imports` *(релиз)* | Полный предоставленный снимок кода и корпуса |
| `tools` | Установка и восстановление данных релиза |

## Проверки

```bash
cd Alfa-Hackaton
news_matching/.venv/bin/python -m unittest discover -s recommendations
news_matching/.venv/bin/python -m unittest discover -s insight_generation
news_matching/.venv/bin/python -m unittest discover -s pipeline -p 'test_*.py'
cd frontend
npm run build
```

Функциональная проверка последней версии: 27 тестов рекомендаций,
14 тестов ИИ-разбора, 13 тестов тематического слоя; проверены реальные эмбеддинги,
различия компаний/ролей и влияние отдельного просмотра. Эти проверки не являются
оценкой precision на ручной разметке. История конечна: после прочтения корпуса
нужен новый сбор, чтобы сохранять неповторяющиеся страницы.
