## Воспроизводимый пересчёт

Из каталога приложения, в Python 3.12 с зависимостями
`news_matching/requirements-gpu.lock`:

```bash
python pipeline/import_snapshot.py /путь/к/alfa-final-dataset-2026-10-25-0900 \
  imports/alfa-final-dataset-2026-10-25-0900
python pipeline/build.py --backend mps \
  --snapshot imports/alfa-final-dataset-2026-10-25-0900 \
  --output pipeline/output-updated
python pipeline/ranked_catalog.py \
  --catalog pipeline/output-updated/catalog.sqlite \
  --output pipeline/output-updated/ranking.sqlite
```

Для ускорения повторного пересчёта можно заранее скопировать из текущего
`pipeline/output` в output-updated файлы article_chunks.jsonl,
article_chunk_embeddings.npy, embedding_metadata.json и reranker_cache.json.
Кэш используется только при совпадении Article ID/content_hash и весов E5.
Не меняйте токенизацию/чанкинг без отдельной инвалидизации старого кэша.

CPU-вариант: `--backend cpu`; векторы исходного Torch и INT8 ONNX считаются
разными и не переиспользуются между ними. Групповые векторы сохраняются рядом
с векторами статей, чтобы отраслевой слой использовал тот же энкодер.

Основная сборка берёт общий файловый lock. Выходной каталог можно собирать
отдельно от рабочего. Перед публикацией требуются проверка целостности SQLite,
состыковки ID/content_hash чанков, нормализации/конечности векторов, запрета
Telegram для ML, ранжирования и страниц реальной выдачи. Сохраните пользовательский
feedback.sqlite, а старый каталог оставьте для отката. API после публикации
нужно перезапустить, чтобы он перечитал новые векторы.

## Память M4

Исходный длинный MPS-прогон с переменной формой входов и batch=24 переполнил
память после нескольких тысяч фрагментов. Torch-инференс теперь ограничивает
batch восемью, использует одинаковую длину padding внутри вызова, удаляет
временные тензоры и освобождает незанятый MPS кэш. Лимит MPS оставлен включённым
и снижен до 0,65 рекомендованного объёма. Это не квота от физической RAM.
Документированный PyTorch способ — освобождение незанятого кэша, а не
отключение ограничителя памяти.

Результаты аппаратной пробы и различие между обработкой и дообучением:
[`TRAINING_READINESS.md`](../news_matching/TRAINING_READINESS.md).
