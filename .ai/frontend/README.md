# Web-интерфейс

Next16.4.3 / React19.3.0, версии в package-lock.json. `npm ci`,
`npm run lint`, `npm run build -- --webpack`, `npm start`.
Локальный `npm run dev` и `./run_mock.sh` запускают Next с webpack: в этом
окружении Turbopack вызывал повторные Fast Refresh без изменения исходников.
Фирменный знак для сайдбара: `frontend/public/alfa-bank-logo.svg`; фавикон:
`frontend/app/icon.svg` и совместимый `favicon.ico` из того же знака.
При первой загрузке сайта прелоадер показывает красный знак без квадратной
подложки (`frontend/public/alfa-bank-mark-red.svg`) на белом фоне. Знак плавно
появляется и исчезает, затем открывается страница; при сниженной анимации
заставка сразу скрыта. Внутренние переходы между маршрутами её не повторяют.
Полный запуск с Python API — [service/README.md](../service/README.md).

Активные маршруты: `/`, `/feed`, `/clients`, `/profile`, `/event`, `/chat`,
`/sources`, `/trace`, `/settings`, `/quality`, `/architecture`, `/docs` (Swagger UI),
`/kit` (библиотека компонентов для команды).
Главная и все разделы используют реальный выбранный company/source_record/user.
При входе на пользовательский маршрут открывается четырёхшаговый Sheet,
если пользователь ещё не закрыл и не завершил онбординг. В панели —
иллюстрации с официального CDN Альфа-Банка, плавное появление и смена шагов.
Кнопка «Показать в интерфейсе» запускает восьмишаговую экскурсию по страницам:
выбор компании, контекст, роль, вкладки и карточка ленты, разбор конкретной
новости, материалы банка и журнал агента. Экскурсия сама открывает нужные
страницы, прокручивает до элемента, подсвечивает его, затемняет фон и показывает
подсказку со стрелкой. На шаге разбора она передаёт ID первой доступной новости
из ленты; при пустой ленте показывает страницу события без статьи.
При переходе между шагами прокрутка сразу ставит целевой блок на место;
подсветка плавно проявляется без перемещения по старым координатам.
Переход по ссылке из панели не завершает онбординг: шаг сохраняется. Незаконченная
экскурсия также восстанавливается после перезагрузки. Закрытие, пропуск и
завершение прекращают автопоказ; на главной кнопка «Посмотреть экскурсию» запускает
его заново. Состояние хранится только в localStorage текущего браузера; профиль
компании и роль остаются на сервере. Внутренний `/kit` не показывает онбординг.
Главная открывается hero по высоте содержимого с иллюстрацией Альфа-Банка,
объяснением сервиса и двумя основными действиями. Ниже показаны текущий контекст,
четыре шага работы, переключаемые карточки возможностей и входы в разделы.
Горизонтальное верхнее меню удалено на всех маршрутах; на desktop навигация
остаётся в сайдбаре, на мобильном — в drawer по плавающей кнопке снизу слева.
Синтетический режим clean-checkout явно маркируется по health.dataset_kind:
в правом нижнем углу виден небольшой круглый индикатор. По нажатию он
раскрывается в уведомление с полным пояснением; повторное нажатие сворачивает его.

`LiveProvider` хранит общую выбранную компанию и тестовый ID пользователя;
профиль, уточнения, роли/темы, реакции и разборы хранятся на сервере.
`RecommendationFeed` — поисковая лента, реакции и drawer текста/экстракта;
`Workspace` — профиль, реальный разбор с polling jobs, follow-up, PDF,
инструментальный trace и мониторинг. `?article_id=...` открывает событие напрямую.
Статусы выполнения задачи и достаточности доказательств разделены.

В ленте «Читать» открывает новость в Sheet справа. Смена компании, настройки
ленты и «Ваш контекст», пояснение «Как устроена подборка» также открываются
справа; панели закрываются
кнопкой, Escape и нажатием на затемнённую область. На узком экране панель
выезжает снизу и закрывается свайпом вниз, когда содержимое прокручено к началу.
Открытие и закрытие анимированы с учётом reduced motion. Кнопки, пиктограмма
закрытия и переключатель текста используют компоненты `UI/*`.

Браузер вызывает `/api/live/*`; BFF передаёт только разрешённые endpoints
в `ALFA_API_URL` (по умолчанию локальный8091). Ключ LLM в браузер не попадает.
Оригиналы PDF идут через тот же proxy и открываются на `#page=N`.

`src/data` и старые макетные компоненты сохранены для совместимости исходников;
активные маршруты не используют их как факты. Нет вымышленных финансовых
счетов/долга/имён клиентов или заранее заданных latency/precision в trace.
Технический seed тоже не является реальной новостью или обучающим корпусом.

При изменениях сначала читать AGENTS.md и соответствующие bundled Next docs.
Для приёмки — production build + CUA/browser сценарий смены компании, новости,
разбора/диалога, источника и reload; не только HTTP200 страниц.

`/kit` показывает существующие `UI/*` компоненты, токены из `app/globals.css`
и образцы пустого, ожидающего и требующего проверки состояний. Примеры на
странице не читают каталог и не являются бизнес-данными. Онбординг и уведомление
синтетического каталога на этой внутренней странице не показываются. Пример
`UI/Drawer` показывает правый Sheet и его мобильное нижнее положение.
Пустые результаты используют общий `UI/Empty`: иконка Iconly, заголовок,
пояснение и необязательное действие. Он показан в `/kit` и применяется в ленте,
поиске компаний, источниках, журнале, истории сценариев и таблицах. Ошибка API
отображается отдельно от пустого результата, ожидание — через `Skeleton`.

Визуальная основа обновлена по публичному Core Components Альфа-Банка:
[источники, токены и правила использования](DESIGN_SYSTEM.md). Общие цвета и
контролы применяются к активным маршрутам. Компоновка рамки приложения
обновлена по пользовательскому скриншоту Альфа-Бизнеса: компактное меню без
подложки с читаемыми подписями, скруглённый знак, вкладки и светлые поверхности. Иконки взяты из
MIT-пакета [React Iconly](https://github.com/jrgarciadev/react-iconly) в стиле
`light`. Часть внутренних цветов экранов остаётся заданной напрямую;
их миграция и полная UX-приёмка входят в последующую доработку.

Лента `/feed` занимает ширину области контента общей рамки без собственного
центрирующего `max-width`. Над группой «Для команды банка» в боковом меню
увеличен интервал; тот же интервал задан в мобильном меню.
Быстрый выбор компании и источника в ленте использует общий `UI/FilterPills`.
Действие «Все компании» открывает список, а длинная группа на мобильном
экране прокручивается горизонтально. На ширине до 950 px лента занимает одну
колонку.
Вкладки «Для вас», «Сохранённое» и «Все новости» используют одну красную
полоску: она плавно перемещается под выбранный пункт и меняет ширину вместе
с ним. Положение обновляется при изменении счётчика и размеров окна;
при предпочтении уменьшенной анимации движение отключено.

Реакция «Полезно» после записи события показывает заполненное красное сердце и
подпись «В полезном». Уведомления о реакциях, сохранении, скрытии и других
успешных действиях используют общий `ToastProvider`: несколько карточек с
иконками складываются сверху справа, выезжают горизонтально и плавно исчезают.
Тень у карточек лёгкая. При скрытии доступна отмена.
При `prefers-reduced-motion` анимация отключается.

Ожидание API в ленте, поиске компаний, профиле, источниках, журнале, метриках,
разборе и истории сценариев показано скелетонами по форме списков и карточек.
Элементы списков появляются FadeInUp; скелетоны появляются и уходят за 0,3 с.
Переход между маршрутами анимирует уход страницы вверх и появление новой снизу
вверх за 0,3 с через React ViewTransition. При reduced motion движение отключено;
браузеры без View Transitions переходят между страницами обычным способом.
