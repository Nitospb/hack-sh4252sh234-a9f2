# Сопоставление показателей и версий источников

Реализация: `pipeline/facts.py`, политика `explicit-source-facts-v1`, runtime
`grounded-agent-v15`. Это детерминированное дополнение к анализу источников.
Обучение и подбор порогов на текущих ответах не выполнялись.

## Что получает пользователь

Reader, анализ и страница банковских материалов показывают сопоставимые
утверждения, точные фрагменты, ссылки, даты, показатель, объект и период.
Совпадение чисел не доказывает независимость публикаций или истинность факта.
Отсутствие числового сопоставления не отменяет качественного объяснения влияния.

`/article` возвращает `story.fact_comparison`; результат нового анализа —
`source_comparison`. `/bank-sources` возвращает `forecast_evidence` с отчётом
и `additional_passages`. Старые результаты без новых полей остаются доступными.
Каждое утверждение имеет source_id, стабильный id, text_sha256, raw/start/end,
quote/quote_start/quote_end, исходные единицы, нормализованные Decimal значения,
показатель, объект, период, тип, методику и missing_context. Цитаты проверяются
срезами исходного текста; offsets относятся к переданному тексту источника.

## Правила сравнения

Явные показатели: ключевая ставка, инфляция, ВВП, выручка, чистая прибыль,
безработица, производство, экспорт, импорт. Словарь ограничен RU/EN. Неизвестные
имена компаний и показатели не угадываются. Страны определяются только явно;
юридические лица — по явной форме и кавычкам. Заголовок дополняет лишь лид.
Показатель требуется в самом утверждении: даже первая цифра лида не наследует
его из заголовка. Объект и год из заголовка не переносятся на последующие абзацы.

Сравнение требует совпадения показателя, объекта, периода, единицы, вида
величины и заданных признаков методики: конец года/среднее, г/г или м/м,
МСФО/РСБУ, real/nominal и сценарий. Неизвестные поля не достраиваются.
Проценты и п.п., разные валюты, годы, компании и сценарии не склеиваются.
Рубли с явными масштабами приводятся к одной единице; валюта для «млрд»
без названия остаётся неизвестной. Незавершённый период не считается итогом.

Статусы:

| status | Смысл |
| --- | --- |
| same_value | Значения одного контекста совпадают |
| overlapping_ranges | Интервалы пересекаются |
| forecast_vs_reported | Прогноз и опубликованный результат |
| different_forecasts | Разные прогнозные оценки без автоматического победителя |
| forecast_revision / later_forecast | Явный пересмотр или более поздний собственный прогноз того же автора |
| revised_observation | Более поздняя явная корректировка того же автора |
| reported_difference | Опубликованные значения различаются; истинное не выбирается |

Приоритет новому прогнозу возможен лишь при известных разных датах, том же
авторе и контексте, достаточно определённой методике и собственном прогнозе
издателя либо явном пересмотре. Новая статья с чужой старой оценкой не становится
обновлённым прогнозом. Прежние значения и страницы одного документа не создают
самостоятельное подтверждение. OCR tesseract исключён из строгого сравнения;
текстовая формулировка пересмотра может быть показана отдельно без сертификации цифр.

## Банковский поиск и модель

Обычные результаты retrieval сохраняют порядок и оценки. Дополнительно берутся
максимум два более поздних собственных прогноза с точно совпавшим контекстом
из датированного пула за 180 дней (до 500 абзацев). Всего runtime передаёт
не более семи банковских фрагментов. Пустой поиск не расширяется случайными
материалами. Дополнение не доказывает применимость к компании.

Генератор и verifier получают до десяти сравнений и короткие request-local
source/statement aliases; API/trace сохраняют canonical IDs. И после уточняющего
поиска отчёт и aliases пересчитываются. Существующие проверки каждого claim,
цитат, дат, пользовательских фактов и банковской атрибуции остаются обязательными.
Это не меняет Feed scores, веса персонализации, группировку событий или gates.

## Проверка и ограничения

Запуск: `PYTHONPATH=. python -m unittest pipeline.test_facts
service.tests.test_forecast_comparison service.tests.test_contextual_evidence`.
Тесты включают разные контексты, пределы диапазонов, старые/новые прогнозы,
внешнего автора, OCR, source aliases и неизменность выдачи. Регрессии запрещают
привязку роста биржевого индекса к ключевой ставке из заголовка/ранней цифры.

Локальная диагностическая выборка 60 реальных групп обнаружила ошибку наследования
показателя из заголовка; она исправлена до публикации. После исправления найденные
сопоставления были совпадениями ставок, без придуманных конфликтов. Это
диагностика, не независимый gold и не измеренная точность. В проверенных реальных
банковских выдачах числовые фрагменты были tesseract-unverified; новый механизм
не стал приписывать им достоверный пересмотр. Приёмка реальных пересмотров по
проверенному PDF-тексту, независимая оценка сущностей/методик и живая LLM-приёмка
остаются открыты. Дневной LLM-бюджет для этой проверки не увеличивался.

Не расширяйте словарь/эвристики ради количества сравнений. Проверяйте новые
правила на независимых контрпримерах, сохраняйте неизвестность и полезную
качественную оценку. Сборщики по команде пользователя остановлены; для этой
функции их запуск и пересчёт эмбеддингов не требуются.
