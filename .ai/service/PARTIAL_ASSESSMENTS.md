# Оценка прежде уточнений: grounded-agent-v13.2

Задача сервиса — дать пользователю полезную оценку, а не поручить ему провести
анализ самостоятельно. При разумной неопределённости даём качественное влияние,
базовый сценарий и при необходимости альтернативу с явно названными допущениями.
Неизвестные договоры/суммы/индексы не объявляются подтверждёнными фактами.

## Публикация

Production verifier отдельно оценивает первичное событие, каждый claim и позицию
банка. Один неподтверждённый расчёт не удаляет поддержанную оценку/действия рядом.
Для каждого сохраняемого claim нужны известные fact IDs и точные source quotes;
семантический review не заменяет независимую экспертную оценку качества.
Нет/дубликат review — нет поддержки соответствующего пункта. Никаких автоматических
исправлений ложной суммы или превращения её в якобы факт.

Ready означает достаточный полезный результат с оговорками. Для него нужно
поддержанное событие и как минимум один поддержанный персональный тезис с
подтверждённым исходным фактом компании. Отдельный why-блок может быть пуст,
если связь объяснена в оценке/риске/действии. Одних candidate фактов недостаточно.
Обычную оценку нельзя блокировать вопросом о наличии кредита, если уже показан
поддержанный сценарий. Отсутствие суммы ограничивает деньги, а не качественный вывод.

Один обязательный вопрос допустим, когда полезной оценки нет либо пользователь
запросил точную сумму/дату/расчёт и без исходных данных её нельзя обосновать.
Если пользователь сам попросил список параметров, запрошенный список сохраняется
как ответ. Проблемы публичных источников не перекладываются на клиента:
при неподтверждённом событии показываем ограничение сервиса без требования
«самостоятельно перепроверьте всё». Not_relevant не подменяет нехватку доказательств.

Позиция банка может сохраняться при неизвестных договорах клиента, если её
summary/relation/applicability/limitations и цитаты прошли отдельную проверку.
Она не является мнением банка о конкретном клиенте без источника. Неподдержанный
bank_view удаляется отдельно. Флаги РКО/ЗПП не являются кредитной линией.

Числовая формула «14% + спред» требует явного условия привязки к ключевой ставке.
Нельзя угадывать фактические условия договора по флагу плавающего кредита.
Единицы выручки, суммы, доля рынка и численные вероятности остаются неизвестными,
если источники не задают их. Сегодняшнее решение ЦБ не гарантирует траекторию
расходов до конца года.

## Проверка результата

`verification.publication` хранит индивидуальные решения, kept/dropped,
банк/событие и критические вопросы. Version входит в cache key; прежние runs
не меняются. Live пример `5670c45fc3bd4994925f71ca0251a04f` (v13.1, тот же основной
поток публикации, до последнего edge guard v13.2): ready, 6 персональных тезисов,
2 исключённых, bank_published=true, 0 обязательных вопросов. Точная оценка в деньгах
не заявлялась. Ранее v11 на том же событии все персональные блоки были пусты;
это функциональная демонстрация, не статистический benchmark улучшения.

Регрессии: service/tests/test_partial_verification.py + runtime regression,
client ready-with-supported-assessment/candidate rejection, исходные scope/date/
quote/schema/ledger tests. Browser/mobile проверка недоступна, пока browser use
выключен в Work; lint/production build/API smoke не выдаём за визуальную приёмку.
