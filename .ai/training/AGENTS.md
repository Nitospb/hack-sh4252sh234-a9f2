# Инструкции будущему агенту обучения

Прочитай `README.md`, `DATASET_CARD.md`, `ANNOTATION.md`, `RUNBOOK.md`,
затем `configs/mac-m4.json`, `common.py`, `prepare.py`, `runtime.py`, `train.py`
и `evaluate.py`. Текущая задача пользователя — подготовка без обучения.

## Что именно обучать

Цель — дообучение существующей `intfloat/multilingual-e5-small` (384 измерения,
117 653 760 параметров). Это не обучение большой LLM с нуля, не обучение
reranker и не обучение событийного классификатора на всех 10 000 bt_ метках.

1. Сейчас доступна адаптация по заголовкам/текстам: `weak_title_body`,
   конфигурация `configs/mac-m4.json`. Сигнал слабый, не подтверждённая
   релевантность объектов. Считай её экспериментальным кандидатом.
2. Для обучения объектной релевантности используй `supervised_objects` и
   `configs/supervised-objects.json` только после появления одобренных ручных
   оценок в независимых временных выборках. Сейчас таких оценок нет;
   не обходи отказ запуска и не заполняй их автоматическими предсказаниями.

Если будущая команда — просто обучить подготовленную E5, запускается первый
эксперимент с явно зафиксированным слабым сигналом и без внедрения в рабочую
ленту. Если требуется именно улучшить/измерить объектную релевантность, сначала
нужна разметка по ANNOTATION.md. Не обещай улучшение до сравнения.

## Запуск и ограничения

- Любое настоящее обучение — только после прямой команды пользователя.
  До этого допускаются подготовка, `--check-only`, проверка токенизации,
  чтение данных и синтетические unit-тесты без обновления весов E5.
- Запускай из каталога приложения: `python -m training.train ... --run`.
  CLI без --run или --check-only отказывается работать; --check-only
  не создаёт E5/оптимизатор и не вызывает backward.
- Базовые веса и tokenizer только локальные, local_files_only,
  trust_remote_code=false. Никаких LLM API для генерации фиктивной разметки.
- На M4/16 GiB: FP32, micro batch=2, logical batch=16, max_length=384,
  MPS memory fraction=0.65. Не отключай лимит памяти.
- Используется точный gradient-cache/replay с отключённым dropout
  (`model.eval()` при включённом autograd). Не меняй на model.train() без
  реализации восстановления RNG между первым проходом и replay.
- Обычное накопление градиентов не увеличивает число contrastive negatives.
  Не заменяй им текущий logical batch, сохраняя обещание 15 negatives.
- В supervised loss только проверенная отрицательная статья той же темы
  считается отрицательной. Оценка 1 (отрасль) и неизвестные пары исключены.
- Сигналы SIGINT/SIGTERM останавливают после полного optimizer update,
  сохраняют next_batch/epoch/optimizer/RNG. Не убивай процесс сразу при
  штатной остановке. На случай аварии есть последний полный checkpoint.
- `latest/model` и `best/model` — кандидаты, не production. Обучение не
  трогает текущие E5/ONNX, каталог, feedback и прежние ZIP.

## Данные и оценка

Не изменяй `data/news-v1` и его heldouts после начала экспериментов.
Сверяй manifest/checksums. При добавлении ручной разметки создай новый
версионированный bundle из того же исходного news corpus; группы и временные
границы должны совпасть. Запрещены Telegram, accessible_excerpt, неизвестные/
будущие даты, известные точные дубликаты и разметка из выдачи как gold.

Обучение видит train, выбор гиперпараметров/эпох — validation. Test читается
отдельной командой только для финальной проверки выбранного кандидата.
Сравни с исходной E5 на том же bundle/split. Title/body retrieval не равен
бизнес-релевантности, judged-pool recall не равен recall по всему каталогу.

После смены весов заново рассчитай embeddings статей И групп, в отдельный
`pipeline/output-candidate`; не подставляй старые векторы/пороги без проверки.
Публикация кандидата — отдельный шаг после качества и разрешённой пользователем
интеграции. Полные команды и условия отката — RUNBOOK.md.

В итоговом сообщении укажи: объектив обучения/сигнал, bundle hash, число
примеров и шагов, устройство, путь checkpoint, сравнение baseline/candidate,
ограничения метрик, выполненные проверки и менялся ли production.
Не называй подготовку или dry-run законченным обучением.
