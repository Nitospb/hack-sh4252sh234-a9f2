# Подготовленное обучение E5

Этот каталог содержит данные и код **будущего дообучения** существующей
`intfloat/multilingual-e5-small`. Сейчас обучение не запущено, новых обученных
весов нет. Рабочая лента продолжает использовать прежнюю предобученную E5
и готовый reranker. Базовые веса, каталог и feedback не заменяются.

Для агентов: [AGENTS.md](AGENTS.md). Полный порядок команд:
[RUNBOOK.md](RUNBOOK.md). Данные: [DATASET_CARD.md](DATASET_CARD.md).
Разметка объектной релевантности: [ANNOTATION.md](ANNOTATION.md).

## Два разных сценария

| Сценарий | Что оптимизируется | Сейчас готово | Ограничение |
|---|---|---|---|
| weak_title_body | Заголовок находит текст своей новости среди других | 6 124 train / 766 validation / 765 test | Слабый сигнал; не оценка релевантности бизнеса |
| supervised_objects | Запрос существующей объектной группы предпочитает проверенную релевантную статью проверенной нерелевантной | Код и шаблоны; 0 ручных меток | Не запускается до ручной разметки |

Первый сценарий — адаптация энкодера к нашему корпусу, эксперимент. Вторая
задача ближе к реальному назначению тем; её нельзя подменить title/body
метриками. Отраслевые совпадения и автоматические accepted/review не являются
gold labels. Генеративная LLM, reranker, 10 000 событийных тем и обучение
персонального ранжирования здесь не дообучаются.

## Установка и безопасная проверка

Python 3.12, локальные веса из полного релиза. Из каталога приложения:

```bash
python3.12 -m venv training/.venv
training/.venv/bin/python -m pip install -r training/requirements.lock
training/.venv/bin/python -m training.train --config training/configs/mac-m4.json --check-only
training/.venv/bin/python -m unittest discover -s training/tests -v
```

Сейчас подготовлено локальное окружение проверки в
`../.release-downloads/review-venv/`; его можно использовать вместо нового.
Не коммитьте окружения, данные, checkpoint и секреты.

Без --run CLI обучения не создаёт модель и оптимизатор. В этом сеансе
проверены подготовка, контрольные суммы, dry-run и синтетические тесты
арифметики градиентов; E5 с новым тренером не обучалась.

## Как устроено обучение

FP32, mean pooling по attention_mask, L2, префиксы query:/passage:.
AdamW с warmup и cosine learning-rate schedule. На M4 micro batch=2,
logical batch=16, max_length=384, три эпохи. Для 6 124 пар — 383 обновления
на эпоху, 1 149 обновлений всего. Последний batch не теряет примеры.

Gradient-cache сначала считает эмбеддинги без графа, вычисляет loss и
градиент по эмбеддингам на полном logical batch, затем повторяет forward
микробатчами и переносит этот градиент в параметры. Это даёт до 15
in-batch negatives для слабого сценария без графа всех 16 примеров в памяти.
Обычный gradient accumulation такой эффект не даёт. Dropout отключён в обоих
проходах, чтобы replay соответствовал тому же отображению. Это намеренное
свойство тренера, а не забытый вызов model.train().

В supervised режиме loss парный: положительная и отрицательная статьи
проверены для одного объекта. Непроверенные статьи других объектов не
превращаются в отрицательные. Оценка «только отрасль» исключается.

Checkpoint содержит веса, токенизатор, AdamW, RNG, epoch/next_batch/global_step,
хеши данных/кода/конфигурации/исходных весов. Сохранение поколениями и lock
защищают от неполной записи и дублирующего запуска. Хранится latest с состоянием
для продолжения и best/model по validation MRR. Test при обучении не оценивается.
SIGINT/SIGTERM сохраняют состояние после полного optimizer update.

## Состав кода

| Файл | Назначение |
|---|---|
| prepare.py | Проверка новостей, группировка копий, временные splits, слабые пары, задания разметки, обработка одобренных оценок |
| common.py | Конфигурация, хеши, batch plan, метрики |
| runtime.py | Локальная E5, pooling и gradient replay |
| train.py | Dry-run, обучение по явному --run, возобновление, checkpoint |
| evaluate.py | Оценка исходных/новых весов на validation или test без обновления весов |
| compare.py | Сопоставление двух отчётов на одном holdout, без внедрения |
| configs/ | Начальные настройки M4 и будущей объектной задачи |
| tests/ | Проверка фильтров/утечек/метрик/checkpoint и математической корректности replay |
| data/news-v1/ | Локальный версионированный bundle, в Git не входит |
| output/preparation-checks/ | Отчёты подготовки; не обученные модели |

Первичные источники подхода: [E5 и его префиксы](https://huggingface.co/intfloat/multilingual-e5-small),
[gradient caching](https://www.sbert.net/docs/package_reference/sentence_transformer/losses.html#cachedmultiplenegativesrankingloss),
[PyTorch MPS](https://docs.pytorch.org/docs/stable/notes/mps.html).
Их идеи использованы в локальном тренере; sentence-transformers не требуется
как дополнительная зависимость и его Trainer не запускается.
