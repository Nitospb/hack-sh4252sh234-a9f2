# Структура анализа по примеру отчёта банка

Визуально проверена страница 1 `data/reports/ALFA-Macro_Insights-Policy_Rate_11Sep.pdf`
(11 сентября 2026). Текстовый слой отсутствует. Это анализ одного конкретного
примера, а не вывод о полном наборе отчётов. Обложка Gold_digest_August26 также
проверена: она не даёт материала для анализа содержания.

На изученной странице:

1. Дата, предмет анализа и короткий подзаголовок с главным изменением.
2. Каждый абзац начинается с выделенного аналитического тезиса.
3. Тезис подкрепляется числами, сравнением с прежним периодом или изменением
   формулировки регулятора; затем объясняется экономический механизм.
4. Рассматриваются несколько каналов: устойчивые цены, ограничения предложения,
   ожидания, кредитование и бюджет. Это аргументы для вывода, а не список новостей.
5. Заключительный тезис отделяет ожидание аналитиков от состоявшегося решения
   и объясняет пересмотр предыдущего прогноза.

Для нашей новости использовать композицию:
«Что изменилось → подтверждающие данные → механизм → связь с подтверждёнными
особенностями компании → сценарий/ограничения → что отслеживать».
Копировать исторические прогнозы в текущую ленту нельзя: отчёт используется как
пример структуры. Позиция банка в ответе требует конкретного датированного
фрагмента источника и ссылки на страницу.

Композиция добавлена в `prompt.py` без изменения JSON Schema. Сам модуль по-прежнему
не вызывает LLM. Автоматическое OCR, индекс отчётов, retrieval и проверка цитат
остаются отдельным этапом; полного RAG по PDF в текущей реализации нет.
