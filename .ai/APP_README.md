# Alfa: новостная аналитика

Запуск: `docker compose up --build -d` → http://127.0.0.1:3000.
Ключ LLM только в серверном `.env`; без него данные доступны, генерация отключена.
Без полного каталога применяется явно обозначенный синтетический smoke-набор.
